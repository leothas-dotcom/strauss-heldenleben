# Käyttäjän palaute: tarkistuslista jokaiselle renderille

Kaikki käyttäjän antama palaute 29.–31.10.2026 yhtenä listana. **Jokainen renderi käydään tätä
vasten läpi ennen kuin se näytetään**, ja jokaiseen kohtaan kirjataan, miten se on todennettu
(mittaus tai still). Kohtaa ei merkitä hoidetuksi koodimuutoksen perusteella, vaan vasta kun kuva
tai mittaus näyttää sen. Tila: ✅ todennettu · 🔶 korjattu, ei vielä todennettu renderistä ·
❌ auki.
